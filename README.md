# Python Rekenmachine

## Over dit project
Dit is een eenvoudige rekenmachine geschreven in Python.
De gebruiker geeft twee getallen in en kiest een bewerking:
optellen (+), aftrekken (-), vermenigvuldigen (*) of delen (/).
Het programma toont daarna het resultaat.

## Hoe gebruiken?
1. Zorg dat Python 3 geïnstalleerd is.
2. Open het bestand `rekenmachine.py`.
3. Voer het programma uit en volg de instructies op het scherm.

## Wat heb ik geleerd?
- Werken met gebruikersinvoer (`input`)
- Werken met variabelen en getallen
- Keuzes maken met `if` / `elif` / `else`
- Een programma stap voor stap opbouwen
